Move your data to another computer or phone

Nivesh Sahayak Billing works like portable software. Everything you saved (your businesses, customers, items and invoices) fits in one small backup file. Put that file on a pen drive, or send it to yourself, and open it on any other computer or phone.

On the computer or phone you use now

  1. Open billing.niveshsahayak.in.
  2. Press My data at the top of the page.
  3. Press Save a backup file. A file named like nivesh-sahayak-backup-2026-11-04.json is saved in your Downloads folder.
  4. Copy that file to a pen drive, or send it to yourself on WhatsApp or email, or put it in Google Drive or OneDrive.

On the other computer or phone

  1. Copy the backup file from the pen drive to the computer (or download it from WhatsApp, email or Drive).
  2. Open billing.niveshsahayak.in in any browser (Chrome, Edge, Firefox or Safari).
  3. Press My data › Restore from a backup file, and choose the file.
  4. Done: your businesses, customers, items and invoices are all there, with the next invoice number in the same series.

Good to know

  • Nothing is overwritten by mistake. When the other device already has some of the same records, the newer version of each one is kept. Restoring an old file never deletes newer work.
  • Works without internet after the page has opened once. You can make bills at a shop or a site with no signal.
  • One file for every tool. The same backup also carries data from the other Nivesh Sahayak document tools you use, because they share one data home on your device.
  • Keep the pen drive safe. The backup file holds your customers' names, addresses and GSTINs. Don't leave it on a shared computer.
  • On a computer, back up automatically: in My data, choose a folder (a OneDrive or Google Drive folder is best). Every save then also updates the backup file there, so the copy on your other PC stays fresh.
  • Install it like an app: in Chrome or Edge, open the browser menu and choose Install app (on a phone, Add to Home screen). It then opens from its own icon.
